AG-MONITOR 系統操作手冊

🎯 模式一：全自動 AI 蒐證

適合大量影片或長時間空景的自動化過濾與截圖。

  1. 匯入證物：點擊左側「匯入影片」或「匯入資料夾」，支援 .mp4, .265, .dav 等特殊格式。
  2. 畫定防線：在中央畫面上點擊滑鼠左鍵，畫出多邊形的「ROI 感興趣區域」。(點擊左側「清除 ROI」可重畫)
  3. 選擇設定：設定 AI 靈敏度、選擇要捕捉的目標 (人/車)，並設定「蒐證模式」(例如精華雙格或持續追蹤)。
  4. 啟動引擎：點擊「啟動全自動 AI 過濾」，系統會在背景極速掃描。完成後點擊「開啟截圖資料夾」檢視成果。

👁️ 模式二：即時人眼點視

作為專業級證據播放器，支援逐格精確檢視。

  • 點擊右上方切換至「即時人眼點視」模式。
  • 下方將出現播放控制列，支援快轉 (最高 16x)、倒放。
  • 快捷鍵支援：空白鍵 (播放/暫停)、左方向鍵 (倒退一格)、右方向鍵 (前進一格)。
  • 手動截圖：看到關鍵畫面時，可直接按下快捷鍵 C 進行無損截圖。

📸 模式三：數位鑑識照片修復 (SR)

針對模糊的車牌或人臉進行 AI 去噪與超解析重建。

  • 點擊最上方頁籤切換至「數位鑑識照片修復」。
  • 匯入剛才截下來的模糊照片，選擇對應的模型 (車牌強化或人臉特化)。
  • 點擊「開始 AI 高畫質化」，完成後可點擊「儲存鑑識結果」。
