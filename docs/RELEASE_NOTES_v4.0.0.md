# 🚀 AG-MONITOR 智慧影像快篩系統 v4.0.0

這是更名後的首個完整公開版本，將 AG-MONITOR 從鑑識工具重整為監視器影片快速篩選系統，並提供不需另裝 Python、CUDA 或模型的 Windows x64 CPU 可攜版。

## ✨ 主要更新

- **完整離線執行包**：內含 Python 3.13、PyTorch CPU、PyAV、OpenCV、Ultralytics，以及 YOLOv8n、YOLO11n／s、YOLO12n／s 五個模型。
- **全景精華截圖**：保留完整原始畫面與角落 OSD；可選擇是否烙印 AI 標註框。
- **同波車流去重**：相同 Track ID 不重複截圖，新進入的人車則立即觸發新場景圖。
- **靜止車輛過濾**：依累積位移排除路邊長時間不動的車輛。
- **動態引導補償**：ROI 內具有實質位移的區域可採較低偵測門檻，提升夜間、眩光及低對比目標的召回能力。
- **全速批次快篩**：提供不傳送逐幀預覽的 Headless 模式，適合整批影片背景分析。
- **非同步截圖寫入**：正常完成會排空佇列；強制停止會立即捨棄待寫事件，避免介面卡住。

## 📦 使用方式

1. 下載 `AG-MONITOR-Smart-Video-Screening-v4.0.0-win-x64-portable.zip`。
2. 比對同頁提供的 `.zip.sha256`。
3. 將 ZIP 完整解壓縮至可寫入的本機資料夾。
4. 執行 `AG-MONITOR.exe`；截圖與紀錄會保存在 `data` 資料夾。

請勿直接在 ZIP 內執行，也不要只抽出單一 EXE。程式、執行環境、模型與網頁介面必須維持原有相對位置。
